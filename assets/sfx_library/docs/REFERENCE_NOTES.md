## High-level observations

- Short, clearly defined attacks.
- Fast resonant decay with little or no sustained tail.
- Mechanical and tactile UI gestures rather than cartoon effects.
- Repeated micro-transients for typing or text animation.
- Airy noise gestures for movement and transitions.

The first example is approximately 11.54 seconds long and the second approximately 14.49 seconds. Their compilation structure was analyzed only to understand density and gesture types.

## Separation from the references

- No reference waveform is included in this repository.
- No sample was sliced, pitch-shifted, time-stretched or otherwise derived from either video.
- The Qiraa library uses new equations, seeds, envelopes, resonances and file names.
- The reference download and analysis files are intentionally excluded from the package.
