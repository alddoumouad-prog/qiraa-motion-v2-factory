# دليل استخدام مكتبة Tactile UI SFX

## مع قالب Apple Pro Vertical

| الموضع | العائلة المقترحة | مثال |
|---|---|---|
| ظهور عنوان الخطف | Text Reveal | `QT_TXT_001_TextReveal` |
| التكبير 100%→800% | Transitions أو Swipes | `QT_TRN_003_DeepMacro` |
| ظهور سطر عربي | Text Reveal | `QT_TXT_002_LineReveal` |
| دخول بطاقة Bento | Cards | `QT_CRD_005_BentoIn` |
| انتقال بين المشاهد | Swipes | `QT_SWP_003_LowWhoosh` |
| ظهور الشعار في الخاتمة | Transitions | `QT_TRN_010_LogoClick` |
| تفاعل / عبّر / شارك | Taps أو Success | `QT_SUC_002_Complete` |

## مع Motion V2 الكلاسيكي

- البطاقات الافتتاحية الثلاث: ثلاث نقرات قصيرة متقاربة من `Taps`.
- ظهور بطاقة العنوان: `QT_CRD_004_CardSettle`.
- كل سطر عنوان: نقرة مختلفة قليلًا من `Text Reveal`.
- الانتقال إلى اللقطة النظيفة: `QT_SWP_001_SoftSwipe`.
- دعوات التفاعل في الخاتمة: `QT_SUC_009_Ready` أو نقرات منفصلة من `Success`.

## مستويات الصوت

- ملفات WAV مضبوطة على قمة **-15dBFS** لتكون جاهزة لقوالب قراءة ثانية.
- صوت المصدر أو التعليق: **-3dB**.
- الموسيقى عند إضافتها: **-24dB**.
- تجنب رفع النقرات القصيرة أكثر من اللازم؛ قوتها في وضوح الهجمة لا في ارتفاع مستوى الذروة.
- استخدم قناة Sidechain أو خفض الموسيقى 1–2dB لمدة 50–100ms عند الحاجة.

## اختيار الملف

- WAV: للمونتاج والأرشفة وأي معالجة إضافية.
- MP3: للمعاينة والويب والمشاركة السريعة.
- Mono: للنقرات والضغطات والتنبيهات القريبة.
- Stereo: للسحب والبطاقات والانتقالات التي تحتاج حركة ومساحة.
