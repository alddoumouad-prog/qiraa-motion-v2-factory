# البدء السريع: من الحزمة إلى مصنع دائم

## مرة واحدة فقط

1. فكّ ضغط الحزمة. محتوى المجلد هو المصنع، بما فيه مجلد `.github` المخفي.
2. على GitHub أنشئ مستودعًا، ثم ارفع **محتويات المجلد** إلى جذر المستودع مع `.github`؛ لا ترفع ZIP فقط. إذا أردت أن يتمكن الوكيل من القراءة دون رمز، يمكن جعله عامًا بعد مراجعة الملفات؛ سيكون الجميع قادرين على رؤيتها. إذا كان خاصًا فالوصول المصرّح به ضروري. اجعل الفرع الافتراضي `main`.
3. فعّل Actions إذا طُلب منك ذلك وتأكد من ظهور سيرَي العمل: **Transcribe source for Motion V2** و**Produce Motion V2 draft**.
4. انسخ مستند `البرومبت_الثابت.md` إلى ملاحظاتك. إذا كان المستودع عامًا، يمكن لوكيل لديه أدوات تشغيل وشبكة قراءة المصنع والتصيير محليًا دون رمز. لتشغيل Actions أو تعديل المستودع، صادق بيئة الوكيل عبر `gh auth login` أو متغير آمن. لا تلصق الرمز في الملاحظات أو الدردشة.
5. جرّب المشروع الموجود `spec.json` من Actions. تنزيل المصدر قد يفشل بحسب الشبكة وتغيّر سياسة X. الفيديو الناتج من مصدر المثال **مسودة** لأن إذن إعادة استخدام المصدر لم يُؤكد ضمن هذه الحزمة.

## كل فيديو بعد ذلك

غيّر السطر الأول من البرومبت فقط، مثلًا:

```text
المتغير الوحيد: https://example.com/link-to-real-video
```

أو:

```text
المتغير الوحيد: أحدث قصة موثوقة عن استكشاف الفضاء
```

المثال الأول رابط توضيحي وليس مصدرًا حقيقيًا. أعطِ البرومبت لوكيل يملك أدوات بحث وتشغيل وشبكة. إذا كان المستودع عامًا يمكنه نسخ المصنع وتشغيله محليًا دون رمز؛ أمّا Actions فتحتاج حق الوصول. الوكيل يسحب المصدر ويملأ spec ويدير المصنع ويفحص ويسلّم الناتج. إذا تعذر الوصول أو حقوق المصدر أو الفحص، يجب أن يوضح العائق بدل الادعاء بالإنجاز.

## كيف تجري عمليًا داخل المصنع؟

- السير الأول يحمّل المصدر مؤقتًا ويفرّغ الكلمات ووقت كل كلمة، ثم يتيح التفريغ للتنزيل دون تضمين الفيديو في artifact.
- الوكيل يراجع التفريغ ويؤلف المواصفات والمحتوى والتوقيت، ويولّد خمسة ملفات جديدة بالصوت النسائي الأصلي إن كان متاحًا، ثم يستخدم `pre_recorded` والمعالجة الآلية ويرفع المشروع إذا توافرت الصلاحية.
- السير الثاني ينزّل المصدر، ينتج الفيديو، ويُخرج artifact فيه الفيديو ولوحة فحص وتقرير. الوكيل يحمل الناتج ويراجعه ثم يرسله لك.
- أنت لا تكتب spec يدويًا عند كل مرة، لكن يجب أن يمتلك الوكيل أدوات وصلاحيات فعلية ليعمل نيابة عنك. ليست كل الوكلاء أو منصات المحادثة تدعم GitHub أو مشاهدة الفيديو أو سماعه.

## تنبيهان مهمان

- **الصوت:** مقاطع مثال الفضاء بصوتك المختار موجودة في المثال، ولكن معرّف الصوت الذي ظهر في جلسة Arena ليس مفتاح API عامًا. لا يمكن استنساخ نبرة الصوت لنصوص جديدة من المعرّف وحده. عند عدم توفر الصوت الأصلي يُستخدم صوت بديل ويُذكر ذلك صراحة.
- **النشر:** رفع المصنع إلى GitHub لا ينشر الفيديو على منصات التواصل. حقوق الفيديو الأصلي تحتاج تحققًا مستقلًا، ولا يُنشر الفيديو عامًّا دون إذن واضح.
