# تقرير اختبار الهوية الذهبية

## ما اختُبر

- قورنت 12 لقطة بين محرّك النموذج الذهبي الأصلي والمحرّك القابل لإعادة الاستخدام باستخدام **المصدر والنصوص نفسيهما**. بعد تصحيح موضع نص الافتتاحية ونسبة المصدر، كانت اللقطات متطابقة بكسليًا. لا يعني هذا فحص كل إطار أو ضمان التكوين على كل فيديو جديد.
- فُحصت بصمات ملفات الهوية، بما فيها الشعارات المعالجة، أصول المستخدم الأصلية، الخطوط، ملف الصوت المرجعي، كودَي القالب والمزج، وخريطة مؤثرات النسخة الذهبية. يحاول اختبار الوحدات تعديل شعار ويؤكد رفض الهوية المعدلة.
- جرى التأكد من وجود 120 ملف WAV و120 ملف MP3 في مكتبة Qiraa المرفقة، ونجح اختبار المكتبة الأصلي. طُبّق 14 حدثًا صوتيًا من المؤثرات في رندر مثال الفضاء؛ سجل الأصول والتوقيتات في `output/qa_report.json`.
- رُندر مثال الفضاء محليًا بالملفات الصوتية التي اختارها المستخدم؛ اكتمل فك الفيديو وفحص الأبعاد والمدة وأُنشئت لوحة الفحص. يلزم فحص الصوت سمعيًا قبل أي نشر.
- اجتازت الحزمة 16 اختبار وحدات، بما فيها اختبار وهمي لطلب ElevenLabs ورفض غياب الإعدادات دون تغيير الصوت بصمت.
- في إصدار سابق نجح سير الإنتاج الأصلي على GitHub Actions. واختُبر رندر لمصدر ثانٍ محليًا دون GitHub Token.

## ما لم يُختبر

- تحديث الهوية الذهبي الحالي ودعم ElevenLabs الجديد لم يُختبرا على GitHub Actions بعد التحديث. لم يُربط حساب ElevenLabs، ولم يتم إنشاء صوت أو إرسال النصوص إلى API فعلي.
- الصوت المرجعي تسجيل للاستماع، وليس voice ID أو نموذجًا لتوليد نصوص جديدة. مطابقة وصف Voice Design للصوت السابق غير مضمونة؛ يتطلب صوتًا دائمًا مرخصًا وموافقة المستخدم وإعدادًا مرة واحدة.
- المصدر الأصلي للفيديو غير مرفق في المستودع، وإذن نشره لم يتأكد. أي نموذج مستخدم قبل تأكيد الحقوق مسودة للمراجعة فقط.
