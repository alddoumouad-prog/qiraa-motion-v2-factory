# مسار الوكيل عند عدم وجود GitHub Token

هذا المستند موجّه إلى وكيل لديه بيئة تشغيل (Python/أوامر وملفات) وإنترنت. عندما يكون المستودع **عامًا** يمكن قراءة المصنع ونسخه دون مصادقة. اقرأ `AGENT.md` و`docs/SPEC_AR.md` أولًا. لا تتوقف لمجرد عدم توفر GitHub Actions أو connector: شغّل المصنع محليًا بديلًا لها، وقدّم الفيديو مباشرة. الوصول العام لا يمنح حق تشغيل Actions أو الكتابة في المستودع.

## التنفيذ الفعلي للوكيل — دون أن تطلب من المستخدم تنفيذ أوامر

1. انسخ المستودع العام إلى مساحة عملك، أو نزّل أرشيف الفرع الافتراضي. إذا كان المستودع ما زال خاصًا، هذا المسار لن ينجح دون وصول أو حزمة مرفقة؛ وضّح العائق.
2. جهّز بيئة Python، وثبّت `requirements.txt` و`requirements-transcription.txt`. ملفات FFmpeg والرندر والخطوط تأتي من التبعيات والحزمة. يلزم أن يدعم Pillow خاصية RAQM للنص العربي.
3. للحصول على المصدر والتفريغ من الرابط مباشرة في البيئة المحلية:

```bash
SOURCE_URL='ضع رابط المصدر العام هنا' LANGUAGE=en python factory/transcribe_url.py
```

استخدم `LANGUAGE=ar` للعربية أو اترك المتغير فارغًا للكشف الآلي. المصدر ينزل مؤقتًا إلى `work/input.*`، والتفريغ إلى `transcript_output/transcript_words.json`. راجع التفريغ مقابل الصوت والفيديو؛ قد يخطئ التعرف الآلي. لا تضع كلمات مرور أو روابط محمية بتوكن داخل الأمر أو spec.
4. انسخ **التفريغ** إلى مسار دائم داخل جذر المستودع مثل `projects/story/transcript_words.json`. انتبه: يزيل `pipeline.py` مجلدَي `work` و`output` ويعيد إنشاءهما عند كل تشغيل؛ لا تحفظ spec أو التفريغ أو الصوت فيهما. إذا أردت إعادة استخدام المصدر المحلي مع `--source`، انسخه خارج `work` أولًا؛ أو اترك المصنع ينزّله مجددًا من الرابط.
5. ابنِ `projects/story/spec.json` جديدًا من المثال، مع نصوص جديدة ومصدر صحيح وتوقيتات مناسبة وتفريغ المشروع. بعد فحص القصة اختر `creative.mode` من التكوينات المنفذة وسجل زاوية الخبر وسبب الاختيار ونوع الـHOOK؛ انظر `examples/agent_voice_smoketest/creative_spec.json` و`docs/SPEC_AR.md`. يجب احترام دقة الكلمات والـoffset والنوافذ غير المتداخلة وعدد المقاطع والبطاقات. لا تستخدم نصوص مثال الفضاء أو ملفات صوته لحلقة جديدة.
6. يولّد الوكيل التعليق والمداخلات كخمسة ملفات من الصوت النسائي الأصلي نفسه إن كان متاحًا ومؤكدًا في جلسته، ثم يحدد `tts.provider=pre_recorded` ومسارات `audio_file`. تطبق الهندسة والمزج تلقائيًا ولا يحتاج هذا المسار ElevenLabs. `voice-00` غير محمول تلقائيًا بين الجلسات؛ إن تعذر الوصول للصوت الأصلي فاسأل قبل أي استبدال. إذا ظهر خطأ مدة، اختصر النص بدل تسريعه بصورة غير طبيعية.
7. نفّذ:

```bash
python factory/pipeline.py --validate-only --spec projects/story/spec.json
python factory/pipeline.py --spec projects/story/spec.json
```

أو مرّر `--source /path/outside/work/source.mp4` إذا كان لديك المصدر محليًا وبحق استعماله. المحرك يزيل `output` عند بدء تشغيل جديد؛ انقل النتيجة النهائية إلى مجلد تسليم آمن قبل تجربة أخرى.
8. افحص الفيديو المولّد والصوت ولوحة `output/contact_sheet.jpg` وتقرير `output/qa_report.json`. سلّم الـMP4 مباشرة للمستخدم باستخدام أداة عرض الملفات أو رابط تنزيل تدعمه منصتك. لا تزعم الاستماع أو الفحص البصري أو الحقوق إن لم تُتح لك هذه الإمكانات.

## مسار GitHub

إذا كان الوصول المصرح به لتعديل المستودع وتشغيل Actions متوفرًا، يمكن بدلًا من ذلك رفع مشروع مستقل وتشغيل workflow `Produce Motion V2 draft`. لا يمكن تشغيله من حساب مجهول لمجرد أن المستودع عام. لا تضع الرموز في الملفات أو المحادثة. لا تعلن أن التشغيل أو الرندر نجحا إلا بعد فحص حالة التشغيل والـArtifact.

## الحدود

- قراءة مستودع عام لا تجعل نموذجًا بلا أدوات قادرًا على تحميل الفيديو أو تركيب الصوت أو إنشاء MP4. يجب امتلاك بيئة تشغيل وملفات وشبكة؛ عند فقدها اشرح العائق بدل التوقف بادعاء زائف.
- X أو خدمة الصوت أو موديل التفريغ قد ترفض الاتصال. يمكن لوكيل مخوّل اختيار مصدر آخر، أو تقديم السبب والخطوة الضرورية فقط.
- المرجع الصوتي ملف للاستماع لا نموذج توليد، ومعرّف Arena غير مضمون خارج الجلسة الأصلية. الفيديو الناتج يحتاج مراجعة بشرية وحقوق المصدر قبل النشر.
