# قراءة ثانية — مصنع Motion V2 الذهبي

نظام لإنتاج **مسودة فيديو عمودي 28 ثانية** من مصدر مصوّر واحد، بنفس الهوية والتكوين والإيقاع في نسخة «التصويت من الفضاء» التي اختارها صاحب المشروع. يتكوّن من مصنع ثابت، و`spec.json` يملؤه الوكيل، وبرومبت ثابت لا يغيّر فيه صاحب المشروع سوى سطر الموضوع أو الرابط.

> **الحالة:** اختُبر الرندر الكامل محليًا ونجح سير الإنتاج الذهبي على GitHub Actions في نسخة سابقة ([التشغيل](https://github.com/alddoumouad-prog/qiraa-motion-v2-factory/actions/runs/41995802861)). دعم ElevenLabs اختُبر بمحاكاة فقط، وليس بحساب حقيقي. لا ينشر المصنع على منصات التواصل. القراءة دون رمز تتطلب مستودعًا عامًا؛ تشغيل Actions أو الكتابة يحتاجان صلاحية.

## ثلاث قطع

1. **المصنع:** هذا المستودع، وفيه محرّك Motion V2، الشعار، خطوط Cairo وInter، مؤثرات Qiraa، وبرنامج الرندر وGitHub Actions.
2. **`spec.json`:** المثال الجاهز موجود في الجذر. في كل مشروع ينشئ الوكيل نسخة حديثة بناءً على المصدر بعد التحقق والتفريغ؛ لا تكتفِ بتغيير عنوان JSON القديم.
3. **تعليمات الوكيل والبرومبت:** `AGENT.md` في جذر المستودع، و`docs/البرومبت_الثابت.md`. بعد الرفع، يكفي في محادثة جديدة إعطاء وكيل قادر على التنفيذ رابط `AGENT.md` ورابط المصدر؛ إعداد المستودع والمصادقة يحدث مرة واحدة فقط.

## ما ينتجه

- MP4: ‏1080×1920، ‏30fps، 28 ثانية، H.264/AAC، بلا موسيقى.
- 0–0.65ث: افتتاحية خضراء بحلقات حمراء وثلاثة أسطر سريعة.
- 0.65–5.22ث: الفيديو الأصلي وهوية العلامة وبطاقة حمراء للعنوان.
- حتى 23.5ث: فيديو المصدر المتحرك، أربع بطاقات متتابعة، ومداخلتان لا توقفان الصورة (كل كبسولة ثانيتان؛ صوت المداخلة أقصر من ثانيتين ومفلتر مثل الهاتف).
- 23.5–28ث: خاتمة «تفاعل / عبّر / شارك».
- مؤثرات WAV فعلية وفق `assets/sfx/recipe_motion_v2.json`، ومكتبة Qiraa الأصلية الكاملة ذات 120 ملف WAV و120 ملف MP3 ومشغلها محفوظة في `assets/sfx_library/`. التعليق، والـducking، والأصوات متزامنة مع عناصر التصميم.
- الهوية الثابتة والشعارات والخطوط والتكوين موثّقة في `docs/هوية_Motion_V2_الذهبية.md`، ومحميّة بفحص بصمات يمنع تغيرها غير المقصود.
- `output/contact_sheet.jpg`، `output/qa_report.json`، `output/loudness.txt`، `output/used_spec.json`، و`output/transcript_words.json` للمراجعة.

**للوكيل دون GitHub Token:** إذا كان المستودع عامًا ولديك بيئة تشغيل وشبكة، اقرأ `docs/التشغيل_دون_رمز.md` ونفّذ محليًا بدل التوقف. تشغيل GitHub Actions أو الكتابة إلى المستودع يحتاج إذنًا حتى لو كان عامًا.

## الإعداد مرة واحدة على GitHub

1. أنشئ مستودعًا **خاصًا** جديدًا، وفعّل GitHub Actions، ثم ارفع **محتويات** هذا المجلد بما فيها `.github` و`spec.json` و`assets` و`examples`. ارفعها إلى الجذر وليس داخل مجلد زائد. لا ترفع `work/` أو `output/` أو ملفات أسرار.
2. اجعل الفرع الافتراضي `main` وتحقق من ظهور **Actions → Produce Motion V2 draft** و**Transcribe source for Motion V2**. قد توجد تكلفة أو حدود على دقائق التشغيل والتخزين وفق خطة GitHub.
3. سجّل دخول `gh` على الجهاز الموثوق: `gh auth login`. بديلًا استخدم `GH_TOKEN` كمتغير بيئة في جلسة موثوقة، لا في ملف أو برومبت أو دردشة؛ استخدم صلاحيات مناسبة ومحدودة للمستودع، وبحسب الحاجة `Contents: write` و`Actions: write` و`Workflows: write` عند تعديل ملفات workflows، مع `Metadata: read`. تطبيق المؤسسة وسياساتها قد تتطلب موافقة. لا يطلب تشغيل الرندر نفسه أي `GH_TOKEN` كـSecret داخل Actions.
4. ضع رابط مستودعك الثابت في البرومبت مرة واحدة. هذا الإعداد لا يُعاد لكل فيديو.

مثال عبر CLI بعد فك الحزمة وتثبيت Git وGitHub CLI (أنشئ المستودع باسمك الفعلي):

```bash
gh auth login
git init
git add .
git commit -m 'Install Qiraa Motion V2 factory'
git branch -M main
gh repo create qiraa-motion-v2 --private --source=. --remote=origin --push
```

بديل واجهة GitHub: أنشئ مستودعًا خاصًا، وارفع محتويات المجلد؛ الملفات المخفية مثل `.github/workflows/produce.yml` يجب أن تُرفع كذلك. لا ترفع ملف ZIP وحده وتتوقع تشغيله. إن لم يسمح الوكيل بالوصول إلى حسابك، نفّذ الإعداد مرة واحدة بنفسك أو استخدم بيئة مصرحًا لها.

## تشغيل المثال على GitHub

من داخل المستودع بعد تفعيل Actions:

```bash
gh workflow run produce.yml --ref main -f spec_path=spec.json
gh run list --workflow produce.yml --limit 5
gh run watch RUN_ID --exit-status
gh run download RUN_ID -n qiraa-motion-v2-draft -D downloaded
```

استبدل `RUN_ID` بالرقم الفعلي الظاهر في القائمة؛ لا تخمّنه. أو شغّل من تبويب Actions وحمّل الـArtifact من التشغيل. يبقى 14 يومًا ما لم تتغير سياسة المستودع. الوصول إلى الفيديو الأصلي عبر X/yt-dlp يعتمد على الإتاحة والشبكة والحقوق وقد يفشل؛ إن فشل استخدم بيئة مصرحًا لها أو مصدرًا تملكه، ولا تنسخ بيانات تسجيل دخولك إلى المستودع.

## تشغيل محلي

المتطلبات: Python 3.11، إنترنت للتبعيات وتنزيل المصدر، ومساحة كافية. على GitHub يُثبَّت كل شيء داخل العداء. محليًا:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python factory/pipeline.py --validate-only --spec spec.json
python factory/pipeline.py --spec spec.json
# بديل إذا كان المصدر بحوزتك:
python factory/pipeline.py --spec spec.json --source /path/to/space.mp4
```

استخدام `--source` مخصص للاختبار أو مصدر مصرح به، و`source_url` في spec يظل رابط النسبة للمصدر. لا تضع مسار مصدر محلي في spec الخاص بـGitHub؛ العداء لا يراه. النموذج يحتاج 23.5 ثانية قابلة للفك بعد `source_offset_seconds`، وإلا يتوقف بدل التجميد أو اختلاق لقطات. النسخ الأفقية تُقص تلقائيًا إلى عمودي؛ يلزم فحص الوجه/التكوين وقد يلزم مصدر عمودي بديل.

## مشروع جديد: ماذا يفعل الوكيل؟

1. يأخذ موضوعًا أو رابطًا واحدًا، يجد مصدرًا مرئيًا مناسبًا، ويتحقق من سياقه وتاريخه وحقوقه ومن بياناته من مصادر موثوقة مستقلة إن لزم. لا يخترع معلومات أو موافقات.
2. يُفرغ كلام المصدر مع توقيت **كل كلمة**، ويختار كلمتين لهما نهاية واضحة لتبدأ بعدهما المداخلتان. يكتب transcript JSON بالمبنى المعروض في المثال. استخدم `factory/transcribe.py` بعد `python -m pip install -r requirements-transcription.txt`؛ توقيتات التفريغ في وقت المصدر الأصلي، ويطرح المصنع قيمة `source_offset_seconds` للمقارنة.
3. يصوغ ثلاثة أسطر HOOK، أربع بطاقات دقيقة، ثلاثة مقاطع تعليق، ومداخلتين قصيرتين. يضع المداخلتين بعد الكلمتين وفي مناطق لا تتداخل مع التعليق والبطاقات، ويكتب spec يتوافق مع `docs/SPEC_AR.md`.
4. يريد المستخدم الصوت النسائي السابق نفسه. عند توفره في جلسة الوكيل، يولّد الوكيل خمسة ملفات جديدة منه، ويستخدم `tts.provider=pre_recorded` مع المسارات؛ يطبّق المصنع المعالجة الثابتة. لا يتطلب ذلك ElevenLabs. معرّف Arena غير محمول تلقائيًا لجلسات جديدة، والمرجع المسجّل للمقارنة لا للتوليد. إن تعذر التأكد من الصوت الأصلي فاسأل قبل استخدام صوت مختلف. راجع `assets/voice/ملف_الصوت_الذهبي.md`.
5. يرفع spec والتفريغ وملفات الصوت فقط بعد التحقق وعدم تضمين أسرار، ويشغّل Actions؛ يتابع السجل ويحمل ملف الفيديو والأدلة. يتحقق بصريًا وسمعيًا ويصلح المشاكل، ولا يدّعي الفحص اليدوي إذا لم يمتلك وسيلة لذلك.

مثال إنشاء التفريغ بعد تنزيل مصدر مصرح به:

```bash
python -m pip install -r requirements-transcription.txt
python factory/transcribe.py --source /path/to/source.mp4 --output projects/story/transcript_words.json --model base
```

أول تنزيل للنموذج يحتاج إنترنت؛ التفريغ الآلي قد يخطئ ويجب مراجعته مقابل الصوت. بدلًا من جهاز الوكيل يمكن تشغيل workflow السحابي `Transcribe source for Motion V2` برابط المصدر ولغته الاختيارية، ثم تنزيل artifact باسم `qiraa-word-transcript`؛ يُرفع التفريغ فقط وليس فيديو المصدر. يُراجع الوكيل التفريغ ثم يضيفه إلى مشروعه قبل تشغيل الرندر. هذه مرحلة مستقلة وليست توليدًا تلقائيًا لـspec.

## حقوق وأمان وحدود حقيقية

- `facts_verified` تصريح من المحرّر، وليس تحققًا آليًا من الحقيقة. `source_permission_confirmed=false` يولّد **مسودة فقط**؛ أكد الحقوق قبل أي نشر. ذكر المصدر لا يساوي إذن الاستخدام. لا تُضمّن الحزمة فيديو X الأصلي.
- صوت المثال المسجّل هو الصوت الذي اختاره المستخدم للنصوص الخمسة **في المثال فقط**. معرّف Arena `voice-00` مرتبط بالجلسة ولا يشكّل صوتًا محمولًا إلى GitHub. لتوليد نصوص جديدة بالصوت نفسه يلزم مزوّد يدعم الصوت نفسه وترخيصه، أو إعادة اختيار صوت، أو قبول البديل. لا وعد بمطابقة الصوت تلقائيًا.
- الفحص الآلي يختبر البنية، حدود المدد، تزامن نهاية الكلمة في التفريغ، وفك الفيديو، وليس جودة المعنى أو السماع أو المشهد كاملًا. يجب على الوكيل فتح لوحة اللقطات والاستماع ومراجعة المصدر والحقوق؛ وإذا تعذّر يصرّح بذلك.
- بيانات المصدر تُرسل إلى GitHub عند رفع مواصفات أو تفريغات، وقد تُرسل نصوص التعليق إلى أداة الصوت التي يستخدمها الوكيل. المستودع الخاص وArtif​acts ليسا بديلًا عن سياسات الخصوصية.
- لا تدخل كلمات مرور، رموز وصول، أو ملفات تعريف ارتباط في `spec.json` أو النصوص. لا تتجاوز حماية المواقع أو جدران الدفع. اتبع متطلبات المنصات.
- الشعار وعناصر هوية «قراءة ثانية» مخصصة لصاحبها؛ راجع صلاحية إعادة توزيعها. تراخيص الخطوط والمؤثرات في `assets/licenses/`. لا تُفهم تراخيصها كترخيص للمصدر المصوّر أو العلامة.

للتفاصيل التقنية انظر `docs/SPEC_AR.md` و`docs/البرومبت_الثابت.md` و`docs/QA_AR.md`.
